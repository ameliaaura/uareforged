# Getting help

1. **Read the guides first.** Most install questions are answered in [docs/INSTALL.md](docs/INSTALL.md) and on
   the site's [Downloads page](https://uareforged.pages.dev/downloads/) and [FAQ](https://uareforged.pages.dev/faq/).
2. **Questions, setup trouble, "is this normal?"**: ask in
   [Discussions > Q&A](https://github.com/ameliaaura/uareforged/discussions/categories/q-a). Someone who had
   the same problem may already have answered it.
3. **Something is broken**: open a [bug report](https://github.com/ameliaaura/uareforged/issues/new/choose).
   The form asks for your platform, version and log file, which is what we need to fix it.
4. **An idea**: post it in [Discussions > Ideas](https://github.com/ameliaaura/uareforged/discussions/categories/ideas).
   When it is clear enough to build, it becomes a feature request.
5. **A security problem**: see [SECURITY.md](SECURITY.md). Please do not post it publicly.

## What we can't help with

- **Getting the game.** UA Reforged needs the original Urban Assault files, which belong to Microsoft. The
  app's *Get the game* button fetches the community OpenUA Standalone Package from the Metropolis Dawn
  community's own server. We do not host or send game files, and we can't help with other copies.
- **Problems with Meta, Apple or Microsoft accounts**, Developer Mode sign-up, or SideQuest itself.

UA Reforged is a free fan project run in spare time, so answers can take a few days. Thank you for your patience.
